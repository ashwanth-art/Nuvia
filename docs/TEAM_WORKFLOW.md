# Team Workflow

## Goal

Keep all three teammates moving in parallel while building toward one product vision.

## Rules

1. Work from shared docs and fixture files.
2. Each person owns their track.
3. Do not wait for another track to finish before starting.
4. Use mock inputs and outputs until integration.
5. Document every API or file format before integration.
6. Keep pull requests small and clear.
7. Do not mix unrelated tracks in one pull request.

## Suggested Branches

- `feature/decision-core`
- `feature/execution-audit`
- `feature/control-room-agent-assist`

## Weekly Integration Agenda

1. Review contract changes.
2. Review each track's completed output.
3. Update fixture files if needed.
4. Resolve naming conflicts.
5. Merge only stable pieces.
6. Write next week's target.
